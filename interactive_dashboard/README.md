# Interactive Personal Finance Dashboard

A Streamlit-based dashboard that visualizes cash flow, spending patterns, and projected net worth using realistic student-friendly sample data. Use the sidebar to adjust starting net worth, return assumptions, and focus categories.

## Run locally

```bash
pip install -r requirements.txt
streamlit run interactive_dashboard/app.py
```

## Features
- **Scenario controls**: tune starting net worth and annual return assumptions.
- **Overview tab**: see projected net worth and monthly cash flow.
- **Spending tab**: drill into spending by category with area charts and sortable tables.
- **Allocation tab**: compare inflows, outflows, and invested amounts side by side.
