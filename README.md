# Md Zihan Khan Namjlish Portfolio

A modern, single-page portfolio site focused on CS + Finance projects and profile highlights.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive styling and visual theme
- `script.js` — tiny enhancement for auto-updating footer year

## Run locally

Open `index.html` in your browser.

You can customize:

- contact email and profile links in the **Let’s Connect** section
- project descriptions in **Featured Projects**
- highlight cards for your current skills and goals
