# CS-Finance-Portfolio

Projects showcasing CS and Finance skills: trading bot, option pricing, portfolio optimization, and interactive dashboards.

## Interactive Personal Finance Dashboard
A Streamlit app (`interactive_dashboard/app.py`) that models student-friendly income and expenses, lets you adjust return and net worth assumptions, and visualizes cash flow, spending, and allocation insights.

### Quick start
```bash
pip install -r requirements.txt
streamlit run interactive_dashboard/app.py
```
